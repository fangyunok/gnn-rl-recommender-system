# 实验 001：MovieLens-1M LightGCN + Policy Gradient

## 目的

验证图召回与强化学习重排的端到端闭环，并观察相关性、多样性之间的权衡。实验不把合成数据
结果包装成业务收益，所有最终指标均来自 MovieLens-1M 的真实评分日志。

## 数据与防泄漏设计

- 数据集：MovieLens-1M，6,040 名用户、约 100 万条评分。
- 对每名用户按时间戳排序。
- 训练集：除最后两次交互外的历史，用于 LightGCN 图表示学习。
- 验证集：倒数第二次交互，仅用于 Policy Gradient 奖励学习。
- 测试集：最后一次交互，仅用于最终离线评估。
- 固定随机种子：42。

这种 leave-two-out 设计比随机切分更接近“用过去预测未来”，并隔离了策略反馈与最终测试答案。

## 配置

| 参数 | 值 |
|---|---:|
| LightGCN 层数 / 维度 | 2 / 32 |
| GNN epoch | 15 |
| 每 epoch BPR 样本 | 100,000 |
| Policy epoch / 每轮用户 | 3 / 1,000 |
| 候选集 / 推荐列表 | 100 / 10 |
| 最终 BPR loss | 0.561323 |

## 全量用户结果

| 方法 | Recall@10 | NDCG@10 | Coverage@10 | Diversity@10 |
|---|---:|---:|---:|---:|
| LightGCN | 0.034272 | 0.016964 | 0.066919 | 0.611093 |
| LightGCN + Policy（权重 0.2） | **0.034603** | **0.017536** | 0.066919 | **0.695695** |

相对纯 LightGCN，权重 0.2 的策略使 Recall@10 提升约 0.97%，NDCG@10 提升约 3.37%，
Diversity@10 提升约 13.84%，Coverage 保持不变。

## 权重扫描与结论

策略权重从 0.1 增至 0.5 时，多样性持续上升，但 0.5 时 Recall@10 降至 0.033113。
这说明过强的策略信号会把相关物品挤出 Top-10。0.2 是本轮同时改善相关性与多样性的折中点，
不是未经验证的固定超参数。

## 局限性

- 绝对 Recall 较低，主要因为当前只训练 15 epoch，且未进行系统超参搜索。
- 奖励仍是离线代理奖励，不等同于线上点击、观看时长或长期留存。
- 物品多样性暂用主类型不相等衡量，没有使用多标签 Jaccard 距离。
- 还需增加 Popularity、BPR-MF 等基线以及多随机种子置信区间。

原始机器可读结果见 `results/experiment_001_movielens.json`。
